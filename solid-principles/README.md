# SOLID Principles

SOLID principles help design code that is easier to change, test, and extend. In interviews, explain them through examples instead of definitions alone.

## What Interviewers Look For

- Can you identify why a design is hard to change?
- Can you separate responsibilities cleanly?
- Can you use abstractions without over-engineering?
- Can subclasses safely replace parent types?
- Can you keep interfaces focused?
